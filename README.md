# Jogo de Corrida 2D

Jogo de corrida 2D com câmera por trás do carro, que pode girar em volta dele.
Criação: Samuel (direção criativa) · Desenvolvimento: Claude.

## Regras do projeto
- As imagens enviadas pelo Samuel nunca são alteradas; ajustes viram cópias novas.
- Todo o jogo segue o mesmo nível de arte do carro (pixel-art com contorno).
- Nada novo é feito sem a autorização do Samuel.
- Demos em HTML; estrutura pensada para migrar para Godot e Unity (arte, dados e lógica separados).

## Pastas
- `arte/referencias/` — originais do Samuel (intocados)
- `arte/carro-honda-laranja/oficiais/` — ângulos recebidos (intocados)
- `arte/carro-honda-laranja/ajustados/` — versão final (roda bronze 7 raios, emblema SB1, vidro traseiro liso)
- `arte/carro-honda-laranja/sprites/` — 8 direções para a câmera girar + `manifesto.json`
- `demos/giro-camera/` — demo HTML do giro 360° (abrir `index.html`)
- `ferramentas/arte2d/` — scripts que geram os sprites e os ajustes
- `docs/` — decisões e pendências

Detalhes do carro: `arte/carro-honda-laranja/INDICE.md`.
